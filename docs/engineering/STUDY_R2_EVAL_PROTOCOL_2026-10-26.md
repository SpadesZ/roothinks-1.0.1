## 1. 目的與不做的事

- 量測 Study「選段解釋／批判」在**真模型**下的：引文是否真的在原文、是否加入原文沒有的數字、是否提供不確定性、是否保留原文的條件；
  以及（由人類評分）引文是否支持論點、是否過度宣稱、是否有研究用處。
- **不**評估科學推論引擎（Gate A／Gate D 另案）；**不**使用 sealed holdout、私人研究文件或正式資料；**不**以結果調整門檻。

## 4. 機器指標與門檻（客觀、與語言無關）

| 編號 | 指標 | 門檻 |
|---|---|---|
| Q1 | 回傳合法結構化 JSON 的比例 | ≥ 0.95 |
| Q2 | 模型引文中「在原文逐字找到」的比例（只代表引文存在，不代表支持） | ≥ 0.90 |
| Q3 | 模型引文中「原文找不到」（捏造）的比例 | ≤ 0.05 |
| Q4 | 回答中出現原文沒有的數字的段落比例 | ≤ 0.10 |
| Q5 | 提供 low／medium／high 不確定性的比例 | ≥ 0.90 |
| Q6 | 條件中的數字（如 `300`、`0.45`）全部出現在回答中的比例（只算條件含數字的段落） | ≥ 0.80 |

機器門檻全過**只**代表「引文存在、沒有亂加數字、格式與不確定性欄位齊全」，**不代表答案品質或科學正確**。

## 5. 人類評分（主觀，與機器分開）

- 工具輸出盲化評分表（`*.rating.csv`）：評分者看不到執行標籤。每個「找到的引文」判斷是否支持所屬論點（支持／部分／不支持）；
  每段記錄：無根據的斷言數、是否過度宣稱（參考資料集的禁語清單）、是否保留範圍條件、不確定性是否恰當（1–3）、研究有用性（1–5）。
- 至少 2 位評分者，報告一致性（Cohen's κ）。人類門檻：
  H1 被判「支持」或「部分支持」的引文 ≥ 70%；H2 有過度宣稱的段落 ≤ 10%；H3 保留範圍條件的段落 ≥ 80%；H4 有用性平均 ≥ 3.5。
- 只有機器與人類門檻都通過，才可以說「在此資料集上，Study 的選段解釋品質達到預先設定的標準」；仍不可推廣到真實論文。
