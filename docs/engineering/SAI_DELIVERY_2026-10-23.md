## 3. 重現缺陷與修復

| 修前實際失敗 | 修復及保護 |

## 5. 自我稽核與風險

本項是同一實作代理的第二次獨立檢查，沒有冒稱外部 auditor 簽核。除了單元測試，也以真瀏覽器及相反條件對照查到並修復分頁副本刪除、選單誤存、stale 離頁繞過、同秒指紋及跨篇來源覆寫。

- 真實 OCR／LLM 品質、主張是否受證據支持、成稿作者性及 AI 偵測率未量測。影像原件保全已實作，但未全面驗證真實影像格式。
- 合成 Windows／Chromium 結果不代表 Linux/GCP、多 worker、多人壓力、無障礙或中文輸入法皆已通過。
- 正式使用需啟用授權模式；none profile 與內部可省版號的 legacy caller 不提供相同多人防護。
- PDF 檔案、SQL 登記及 library 不是單一交易。失敗會保留原件與 ID 並回報錯誤；尚無自動對帳／孤兒登記修復工作佇列。
- JSON 歷史及本機草稿採小型研究專案的既有儲存方式，長期大量使用的容量與清理策略尚未驗證。
- 一般帳號仍可能看見設定導覽入口，後端會拒絕；角色導覽與教授完整審閱流程可再改善。
- 未讀取正式研究資料驗證，也未部署、執行正式還原、合併 main 或推送 LAVA-Cowork。
- 本輪合成測試站、瀏覽器與專用容器已關閉；06:10 一次性接續提醒已刪除。合成證據留在本機供複查。
