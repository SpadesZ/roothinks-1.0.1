# 小型研究完整性基準：執行契約

日期：2026-10-24。本輪只量測合成管線，不聲稱真實模型或科學品質改善。

## 問題與觀測單位

以兩份明示為合成的證據，固定六個主張案例，走真實作者確認 API 與 Task8 Socket／provider 邊界。觀測單位是案例；兩份來源被重複使用，不能說成六篇獨立論文或六位研究者。

六個案例預先固定：有界量測、跨樣本泛化、遺漏溫度、偽造定位、模擬冒充量測、缺少證據。來源及請求與人工答案分開保存；人工答案只供評分，不進 provider prompt。provider 是受控替身，分別傳回預先指定的好／壞敘述，檢查真實管線與評分器是否保留或辨識這些差異。

## 固定量測

1. 每個接受案例的來源身分、頁碼及伺服器證據快照是否符合原來源。
2. 作者輸入的條件／禁止延伸是否完整保存在決策，並到達最終 dispatch prompt。
3. 已填條件涵蓋多少來源必要條件；此指標與「系統有沒有截斷作者輸入」分開。
4. 固定人工答案中未受支持或缺條件的控制敘述，是否仍出現在輸出。
5. 缺少證據是否拒絕；任何案例是否被系統冒稱已獨立科學驗證。

評分僅匹配固定目錄中的敘述與來源，不是通用語意判斷器；目錄外文字標未知。另以改錯來源、刪掉條件及未知敘述的控制輸入驗評分敏感度。錯誤／拒絕不得剔除，按預定類別計數。這是有限集合的確定性檢查，不作統計推論、模型排名、顯著性檢定或作者風格／AI 率宣稱。

## 執行與界線

命令：`python -m pytest test/unit/test_research_integrity_benchmark.py -q`。資料只在 tmp；不需要教授、真實 PDF、API key 或付費 provider。需要保存觀測時，由測試啟動器指定新的 `SAI_BENCHMARK_OUTPUT` JSON 路徑，既有檔案不可覆寫。

輸出保存資料集／人工答案／評分器雜湊、程式 SHA、案例結果及上述計數。結果可能顯示系統仍允許作者確認、並保留未受支持的控制敘述；這是待補的科學判讀能力，不因來源定位與字串傳遞成功就宣稱通過。正式科學驗收仍須另外固定真實獲授權文獻、盲測人工答案、模型版本與代表性研究任務。
