# I07 科學完整性建議與盲測契約

日期：2026-10-24；起點 `52f7287`；分支 `codex/sai-scientific-advisory`。本契約在新驗證器實作及外部標準答案開封前固定。

## 產品契約

科學驗證是建議，不是研究者的上級。缺證據、矛盾、假說或未知，不得單獨阻擋寫作、保存、修訂、匯出。不得自動改結論，也不得將作者確認當成科學證明。

以來源原文、定位、指紋和目前主張逐項對照。明示數值／適用條件缺漏、可能矛盾、模擬被寫成實測、未找到支持與未知。確切文字對齊只證明文字關係；未被規則涵蓋的語意應棄權。作者可保留假說、修訂、不同意或要求更多證據，理由與原報告追加保存。

I06 原案例保持原文與舊觀測，不把「未支持輸出仍存在」改成刪除輸出才算成功。本輪量測是否新增可追溯警訊，以及作者能否讀到並回應；不以警訊代替科學品質改善。

## 發現原因與安全驗證

先重跑 I06 固定六案例，檢查實際 provider 回應及後處理。先以 session／Socket 負向案例重現剩餘 CSRF、專案列舉、撤權後佇列與結果交付問題，再修共同根因。保留獨立／選用教授／團隊三流程。

## 外部資料及盲測

- 資料：AI2 SciFact（Wadden 等，2020），官方 https://github.com/allenai/scifact 。Claims／證據標註 CC BY 4.0；文獻摘要來自 S2ORC、ODC-By 1.0，依官方 LICENSE.md 分別記錄歸屬。只作離線評估，不下載模型，不讀正式研究資料。
- 官方資料網址：https://scifact.s3-us-west-2.amazonaws.com/release/latest/data.tar.gz 。下載後保存 archive 及各檔 SHA-256；原資料留 TEMP，不加入 repository。
- 完整使用 `claims_dev.jsonl`，不依 label、輸出或難度挑樣本；不讀 train labels 來調規則。每個 claim 是觀測單位，並列共享 document 的數量；不可把重複引用當作獨立文獻。
- 預測器只收到 claim、`cited_doc_ids` 的候選摘要、句子索引與資料身分，不能收到 gold label、rationale、evidence doc 選擇或答案衍生條件。候選選擇不使用 gold evidence；定位由固定文字相關排序產生。
- 外部 claims 的 label／rationale 由原資料集作者在本輪之前建立，並非本實作者撰寫。準備器將 annotations 封在 evaluator-only 檔，先凍結產品驗證器、評分器及推論輸入，再產生並固定預測，最後評分器才開封答案。
- 這是程序上的 label-blind 評估；公共資料可能已被預訓練模型看過，不能稱全新隱藏測試。本輪預設不使用模型；亦不宣稱是新聘領域專家獨立重標。

## 指標及失敗規則

1. 支持／矛盾／未建立支持的完整混淆矩陣；分別列可能矛盾警訊的 TP／FP／FN／TN、precision／recall／FPR／FNR，分母為零列 null。
2. 明確支持與明確矛盾的覆蓋率，以及未知／棄權；不能刪掉棄權以提高成績。文字對齊與語意真實性分開。
3. 相對外部句子 rationale 的定位 precision／recall，僅對有 gold rationale 的案例計算並列分母；不得用 gold rationale 選候選句。
4. I06 及額外固定對抗控制：來源尾端限制、跨樣本泛化、缺條件、數值相反、否定語句、模擬／實測混用、提示注入、錯定位及未知。控制案例與外部人工答案成績分開；條件缺失／新增計數與正文 hash 不變可重現。
5. 外部 SciFact 原答案未直接標註本系統所有「條件流失／模擬誤用」種類；不得冒稱有該類獨立人工 gold。這部分先以明示的變換控制和合成例評估，列為後續專家標註缺口。
6. 預測數量、重複 ID、缺輸入、錯誤、空結果及系統失敗全部列入。若盲測失敗，不在同一批答案上調規則後重報為盲測；修正測試工具錯誤要保留原輪並說明。沒有預設品質 PASS 門檻；本輪交付以工程工作流成立、結果如實呈現為判準。

這是固定小型資料集的確定性基準，不做模型顯著性、因果改善或跨領域推論。不新增付費 provider 呼叫。正式真實文獻品質、作者聲音與專家可用性仍須後續獨立驗收。
