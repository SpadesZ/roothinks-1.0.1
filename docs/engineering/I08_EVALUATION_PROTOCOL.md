## 分離可量測的改動

檢索 R0：I07 句子 Jaccard。R1：同樣候選集、同樣前三句，固定 BM25（k1=1.2、b=0.75）；不用 label、gold rationale 或 gold 文獻選句。索引／句子位置不能改來源原文。

判讀 A0：I07 原句包含／第一候選規則。A1：逐候選的有界語句關係比較，保留主客體次序、方向、否定、數字、適用條件與模態。只對能明確對應的句型給候選判斷，其他棄權；不將 lexical overlap 當通用語意支持。支持與相反證據同時出現時明示 mixed，不替作者決定。沒有安裝 NLI 模型，本輪不讀 provider 金鑰或呼叫付費模型；不得將規則比較宣傳成已驗證的 NLI。

四組 R0A0、R1A0、R0A1、R1A1 使用相同案例與輸入。R0A0 必須與凍結基準的 labels／定位相符；否則先修比較工具。不因分數更好就跳過對抗控制。固定控制涵蓋矛盾來源、主客體顛倒、數值及單位、樣本／溫度、模擬與實驗、外推、缺引用、否定範圍、弱語氣與提示注入。

## 指標與採用界線

- 每組完整混淆矩陣、支持／矛盾 one-vs-rest TP／FP／FN／TN、precision／recall／FPR／FNR；UNKNOWN 及 ERROR 全部留分母。
- 檢索首句及前三句定位 precision／recall／F1；另列有至少一個 rationale 命中的主張比例。共享文獻不當作獨立樣本，不以重複句子增加 n。
- 判讀覆蓋率、棄權原因、mixed 數量；不把 UNKNOWN 當作已正確識別 NEI。定位指標不代表科學真偽。
- 固定條件控制量測遺漏 TP／FP／FN／TN、來源 quote offset 及原稿不變。其標籤是合成機械控制，不能冒充專家金標。
- 診斷改善需同時報 recall 與新增 false positives，不用單一平均分掩蓋矛盾、條件或模擬混淆。若候選增加有害誤判或控制失敗，保留為實驗能力，產品仍採較安全版本。若採用，仍明示規則邊界，不能宣告科學可靠性通過。
- 專家 holdout 的品質門檻先由 owner／領域審查者依使用情境固定，再獨立評分；本輪不自訂專家可接受的漏報或風險容忍。未完成標註列 NOT MEASURED，不補造分數。

## 標註欄位與程序

審查者看完整選定來源及定位，不看引擎結果。逐案填：專業領域、來源主張是否有支持／矛盾／資訊不足／混合、逐句 evidence locators、必要適用條件、主張是否保留各條件、simulation／measurement／observational／mixed／unknown、主客體與因果、外推、缺引用、不確定性、理由及信心。標註人身分與資格由人填寫，不由程式產生。

支持是「在所列來源及條件下有支持」，不是全世界真理。原句摘錄也可能是引述、假說、被否定敘述或缺上下文，不能自動給 SUPPORT。數值變換、加 all、移除引用或模態詞，也不可不讀上下文就預填矛盾。

兩位先獨立標註，再對齊引文／條件及分歧；保留原兩份標註與裁決。不一致率、條件一致率及 Cohen kappa 只能在真標註存在後計算。Gold payload、case manifest、rubric、程式／模型版本及評分 hash 固定後才開封預測；所有更動另立一輪，不覆寫。
