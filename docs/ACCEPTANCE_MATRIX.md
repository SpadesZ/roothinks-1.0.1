## 執行案例

### T01｜第一次使用與可及操作

建立空專案；以未讀內部說明的使用者身分找到閱讀、筆記與下一步。用鍵盤、1280×800 視窗及 200% 字級完成核心操作；輸入中文時組字 Enter 不提前送出。不需 JSON、Task ID 或 S.Ver 才能完成任務。記錄卡住位置，未實測不勾通過。

### T02｜PDF 起步與單一文獻清單

只上傳一篇合成／獲授權 PDF；確認候選條目與 PDF 同時可見。搜尋／匯入同篇，提示可核對合併；保留兩筆來源與既有 ID，不自動 included。填入人類採用理由與閱讀筆記，再確認納入；檢查下游作者脈絡與對應來源。對拒絕合併、同名不同文獻與不同 PDF 版本另驗分支。

### T03｜研究類型與領域

分別建立醫學、工程／光子與探索型問題。填入適用的問題、資料、比較與結果指標，允許未知與不適用。修改研究問題後可看見受影響內容。搜尋角度依領域及問題變化，查詢／日期／來源／篩選可重做；回查 DOI 不能顯示為主張已證實。

### T04｜真正比較與部分失敗

用兩篇答案位於後段、單位／條件有差異的測試文獻，指定基準與自訂維度。更換清單順序不得改變已指定基準。每格能回原片段，指出不可直接比較處；缺資料不排名。分別注入一項、全部 provider 失敗與歷史存檔失敗，確認狀態分開且原錯誤可見。

### T05｜多輪研讀形成主張

先問方法，再追問「在剛剛那個條件下是否仍成立」。確認對話前提及來源延續，後段結果可取回。把對話／比較整理成主張，作者確認前維持提案。用 AI 示意圖、假資料與真實量測各一份，確認不混用為實驗證據。

### T06｜人類決策跨模組接續

在 PAQ、選文、Study 比較／對話、筆記、章節修訂與教授意見各加入不同人類標記與理由；保留一項被拒絕 AI 建議。下一輪寫作攔截實際送出內容，確認適用決策與理由到達、未授權來源不在場；生成稿再由作者核對其含義，不只做字串存在測試。

### T07｜低預算與版本影響

使用長脈絡、重要限制在尾端的筆記與來源，壓縮可用額度；系統必須保留核心條件及足夠證據，否則縮小工作範圍。修改來源指紋、排除文獻、換章節與全文版本；受影響成果標需重核，未解意見不無聲遺失。來源清單須符合最終實際請求。

### T08｜作者聲音與新增主張

作者指定一段原稿、兩個必留判斷、一個限制與一段風格樣本。分別執行保守潤飾與重整；原文、差異與可還原行為可驗。故意要求超出證據的泛化，結果須指出支持不足而非把它寫成事實。記錄人類關鍵決策保留、AI 新增主張及人工修訂量；不採用 AI 偵測器分數作通過證據。

### T09｜跨角色與模型管理

用管理者、一般成員、限定共同作者、非成員及未登入者，測試頁面、API、Socket、匯出與上下文。普通成員與限定編輯對全站模型管理寫入應為 403；未登入 API 401；授權管理者可以操作。對章節、全篇、他專案、模型請求與資源下載各測一次；確認伺服器操作者無法偽填。

### T10｜教授意見到學生回覆

教授選定 v1，對一個段落／主張留意見與資源。學生在相關工作區讀到同一意見並回覆，產生 v2 後連結修改處；教授比較 v1/v2、查看原證據並確認完成或繼續討論。另測不同審閱者、跨章限定作者與意見跨版本未解情況。

### T11｜多人保存與離頁恢復

兩個使用者、同人兩舊分頁分別從同一版本編輯。先保存 A，再保存過時 B；不得無聲覆蓋。注入磁碟／鎖定失敗、斷線及輸入後立即離頁，重新開啟可找回未保存內容，沒有顯示假成功。確認私人草稿不變成他人可讀內容。

### T12｜長任務、費用、取消與重啟

用可控制的合成任務模擬 queued／running／partial／failed；在某階段完成後重啟，核對 job_id、輸入與已完成結果，只重試缺項。模擬 429、timeout、取消前後 provider 返回及未知價格；成功、保存、降級、實際已用 token 與可估費用分開。任務在已授權預算內續行，超限不悄悄增加支出。

### T13｜固定版本的真正輸出

選定已確認全文版本，含中文／英文、至少一張圖、一個表格／公式、caption、正文引用與文末書目。從 Submit 匯出並在離線環境開啟，檢查編號、來源、缺圖阻擋與檔案完整性。確認產物清單含稿件／章節／模板版本與雜湊；舊稿不改變，也未對外投稿。

### T14｜健康、容量與一致還原

在隔離環境停用必要服務，確認「程序在線」與「研究功能可工作」不同。測試長任務下閱讀／保存，先記錄資源及延遲基線，再固定容量門檻。以一致快照備份／還原，核對原 PDF、草稿、歷史、決策、引用、圖像與附件互相可定位。空 JSON 或任意檔案不能使研究品質／審查完成。

### T15｜科學品質與檢索條件
