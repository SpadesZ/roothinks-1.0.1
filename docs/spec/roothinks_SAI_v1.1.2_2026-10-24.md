## SCI-ADV：作者可檢視、可反對的主張證據比較

1. 科學驗證只提供建議。未支持、矛盾、缺條件、假說、未知及未回應警訊，不得單獨阻擋寫作、保存、修訂或匯出。教授帳號與教授核准均非必要。
2. 不自動改寫結論。保存被比較的原文、來源原句、定位、來源指紋、規則版本、產生者及時間。文字對齊、來源可定位和作者確認均不是科學證明。
3. 顯示未建立支持、可能矛盾、數值未對應、適用條件未明示、模擬被寫成實測等警訊及理由。未涵蓋的語意明示未知；鄰文已述條件、不同樣本及來源間衝突須人工判讀。
4. 比較可選未保存的原文與零份證據。來源由伺服器依專案及章節 ACL 取得，拒絕客戶端偽造文字／定位。限定作者只能看已交付的來源快照。
5. 作者可追加「保留為假說／準備修訂／不同意／需要更多證據」及理由。原報告不改寫，回應不提升為科學證明。來源變更顯示歷史報告過時；舊檢視回應拒絕，重新載入後保留未送出的理由。
6. 生成後以已選人類決策的來源及條件比較；沒有選定證據時明示。建議故障不得丟棄或改寫模型原稿，應顯示無法完成並容許後續寫作。
7. 報告及回應納入研究歷史與既有受控停機備份。權限撤銷與科學建議分離：撤權可阻止存取或保存，科學警訊本身不可限制作者。

本版採確定性文字規則，只分析最相近候選，另列前三句供作者核對。句子切分、同單位數值、部分中英文提示詞及條件詞不等於完整語意驗證。最多 16000 字、八份證據、64 句；超限明確拒絕比較，不截掉限制，也不拒絕保存稿件。

## 可重現驗收

| 案例 | 可觀測結果 | 證據邊界 |
|---|---|---|
| S01 | I06 壞主張原文保持，新增對應警訊及來源定位 | 合成控制，不代表學術結論正確 |
| S02 | 主張／來源／作者條件逐項可讀；作者可反對並保留假說 | 文字比對非科學真偽判定 |
| S03 | 無證據仍保存草稿、修訂、真 DOCX；分析／保存建議故障仍交付原稿 | session、API、Socket 及真瀏覽器 |
| S04 | 來源變更 409、重新載入保留理由、追加歷史；報告及回應還原逐字一致 | 既有單機停機備份範圍 |
| S05 | 猜來源、偽 actor／定位、跨章、撤權、CSRF、登出舊 Socket 拒絕 | 指定邊界，非全站安全認證 |
| S06 | 引擎／推論／評分先固定，完整 SciFact dev 預測先落盤再評分 | 公共資料的 label-blind，不是新隱藏集 |
| S07 | 混淆矩陣、FP／FN、棄權、定位、條件控制及全部失敗保留 | SciFact 無本產品全部條件／模擬標籤；專家 gold 待補 |
| S08 | 獨立、選用教授、團隊三流程維持；教授移除不刪歷史 | 延續 A01–A05，科學警訊不新增角色前提 |

外部量測品質不足時不得以單元測試數量或低誤報宣告科學通過。後續須由獨立領域審查者先固定代表性條件／模擬／因果 gold、可接受誤報漏報及保留集，才能作新一輪科學驗收。見 [I07 盲測契約](../engineering/SAI_SCIENTIFIC_ADVISORY_PROTOCOL.md)及[交付與限制](../engineering/SAI_SCIENTIFIC_ADVISORY_DELIVERY_2026-10-24.md)。
